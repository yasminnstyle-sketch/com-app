# Compacto — внутренняя система

Проекты, снабжение, касса, поставщики. Отдельный сайт со своей ссылкой, без Claude.

Ничего не бесплатно навсегда, но для одной небольшой компании оба сервиса ниже
укладываются в бесплатный тариф.

---

## Шаг 1. База данных (Supabase) — 10 минут

1. Зайди на **supabase.com** → Sign up (можно через Google) → New project.
2. Придумай пароль базы данных (сохрани его куда-нибудь), выбери регион
   (ближайший — Europe или Singapore), нажми **Create new project**. Подожди
   1-2 минуты, пока проект создастся.
3. Слева меню → **SQL Editor** → **New query**.
4. Открой файл `sql/schema.sql` из этой папки, скопируй всё содержимое,
   вставь в редактор → нажми **Run**. Должно написать "Success".
   Это создаст все таблицы (проекты, позиции, касса, поставщики, платежи).
5. Слева меню → **Project Settings** (шестерёнка) → **API**.
   Тебе нужны два значения:
   - **Project URL** (выглядит как `https://xxxxx.supabase.co`)
   - **anon public key** (длинная строка)
   Сохрани их — понадобятся в шаге 2.

## Шаг 2. Сайт (Vercel) — 10 минут

1. Зайди на **vercel.com** → Sign up (можно через тот же Google).
2. Тебе нужно, чтобы эта папка (`compacto-web`) оказалась в твоём GitHub —
   самый простой способ:
   - Зайди на **github.com** → New repository → назови `compacto-app` → Create.
   - На странице нового репозитория нажми **uploading an existing file**,
     перетащи туда все файлы и папки из `compacto-web` (кроме `node_modules`,
     если он у тебя появился) → Commit changes.
3. Вернись в Vercel → **Add New** → **Project** → выбери репозиторий
   `compacto-app` → **Import**.
4. Перед деплоем разверни **Environment Variables** и добавь две штуки:
   - `NEXT_PUBLIC_SUPABASE_URL` = тот Project URL из шага 1
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = тот anon public key из шага 1
5. Нажми **Deploy**. Через минуту-две получишь ссылку вида
   `compacto-app.vercel.app` — это и есть твой сайт.

## Готово

- Открой ссылку с телефона → **Поделиться → На экран «Домой»** — появится
  иконка как у обычного приложения.
- Ссылку можно скинуть мужу/снабженцу — данные общие для всех, у кого есть
  ссылка. Логина и пароля нет — значит, ссылку никому чужому не давай.

## Что делать, если что-то не собралось на Vercel

Скинь мне текст ошибки из вкладки **Build Logs** в Vercel — разберём.

## Файлы в этом проекте

- `app/page.js` — вся логика и интерфейс (проекты, снабжение, касса, поставщики)
- `lib/catalog.js` — встроенный справочник материалов, фурнитуры и услуг
- `lib/supabaseClient.js` — подключение к базе данных
- `sql/schema.sql` — структура базы данных (таблицы)
